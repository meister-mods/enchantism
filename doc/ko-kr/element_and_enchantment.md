# Enchantism 원소 재료 및 인챈트 조합식

## 1. 원소 추출

원소 주입기는 재료 1개를 소비하여 원소가 담긴 통에 지정된 양의 원소를 추가합니다.

### 1.1. 단일 원소 재료

단일 원소 재료는 빈 원소가 담긴 통 또는 같은 종류의 원소가 담긴 통에만 사용할 수 있습니다.

예:

```text
조약돌 1개 → STONE 10
```

* 빈 컨테이너에 넣으면 STONE 컨테이너가 됩니다.
* STONE 컨테이너에는 추가할 수 있습니다.
* WOOD 등 다른 원소 컨테이너에는 넣을 수 없습니다.

### 1.2. 복수 원소 재료

일부 재료는 둘 이상의 원소로 해석할 수 있습니다.

예:

```text
뼛가루 1개
├─ 빈 컨테이너 → DUST 4
└─ LIFE 컨테이너 → LIFE 3
```

빈 컨테이너에서는 등록된 **기본 원소**가 선택됩니다. 이미 특정 원소가 들어 있는 컨테이너에서는 해당 재료가 지원하는 동일 원소를 추출합니다.

### 1.3. 판정 우선순위

```text
개별 등록 재료
→ 압축 조약돌 특수 판정
→ 원소 태그 기본값
→ 사용할 수 없는 재료
```

개별 등록된 수치가 태그 기본값보다 우선합니다.

* 참나무
* 가문비나무
* 자작나무
* 정글나무
* 아카시아나무
* 짙은 참나무
* 맹그로브나무
* 벚나무
* 진홍빛 판자
* 뒤틀린 판자

```text

```

원목과 네더 자루의 원소량은 모두 같습니다.


| -------- | --------: |
| 철 조각     |   METAL 3 |

철과 금은 조각 9개가 주괴 1개인 제작 관계를 보존합니다.

```text

금 조각 9개 × 4 = 금 주괴 36
```

네더라이트 주괴는 제작 재료의 원소량을 합산합니다.

```text
네더라이트 파편 4개 × 70
+ 금 주괴 4개 × 36
= METAL 424
```

## 3. 인챈트 부여기

### 3.1. 슬롯

인챈트 부여기는 슬롯 위치에 따라 고정된 원소량을 소비합니다.

| 슬롯 | 소비량 |
| -: | --: |
|  0 |  90 |
|  1 |  80 |
|  2 |  70 |
|  3 |  60 |
|  4 |  50 |
|  5 |  40 |
|  6 |  30 |
|  7 |  20 |
|  8 |  10 |

최대 소비량:

```text
90 + 80 + 70 + 60 + 50 + 40 + 30 + 20 + 10
= 450
```

빈 슬롯은 무시됩니다.

---

### 3.2. 조합식

각 인챈트 조합식은 다음 값으로 구성됩니다.

```text
주원소 비율
+ 선호 주원소 총량
+ 선호 또는 기피 촉매
+ 금지 원소
+ 기본 점수
+ 비율 민감도
```

#### 주원소

인챈트의 핵심 배합입니다. 실제 비율이 목표 비율에 가까울수록 높은 점수를 얻습니다.

#### 선호 주원소 총량

주원소의 합계가 이 수치에 도달하면 원소량 보정을 완전히 충족합니다. 초과분은 추가 점수를 제공하지 않습니다.

#### 촉매

주원소 비율 계산에는 포함되지 않지만 최종 점수를 보정합니다.

```text
+0.30 → 최대 30% 증가
-0.25 → 최대 25% 감소
```

촉매 선호량보다 적게 넣으면 비례하여 일부 효과만 적용됩니다.

#### 금지 원소

금지 원소가 포함되면 해당 인챈트의 점수는 0이 됩니다.
